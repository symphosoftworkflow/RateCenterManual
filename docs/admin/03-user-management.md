# บทที่ 3 — การจัดการผู้ใช้งาน

*DOC-ADM-001 v1.0 | คู่มือผู้ดูแลระบบ*

---

## 3.1 ภาพรวม

ผู้ดูแลระบบสามารถบริหารจัดการบัญชีผู้ใช้งานผ่านหน้า **User Management** ซึ่งอยู่ในเมนูด้านซ้ายของระบบ

**สิทธิ์การเข้าถึง:** Admin และ Superadmin เท่านั้น

- **Admin** — จัดการผู้ใช้งานในบริษัทของตนเองได้
- **Superadmin** — จัดการผู้ใช้งานทุกบริษัทในระบบได้

---

## 3.2 การดูรายชื่อผู้ใช้งาน

<div class="procedure">

1. คลิกเมนู **User Management** ในแถบนำทางด้านซ้าย
2. ระบบแสดงรายชื่อผู้ใช้งานทั้งหมดในบริษัทของท่าน
3. สามารถค้นหาผู้ใช้งานได้จากช่องค้นหา หรือกรองตามบทบาท (Role)

</div>

**คอลัมน์ที่แสดง:**

| คอลัมน์ | คำอธิบาย |
|---------|---------|
| ชื่อผู้ใช้ (Username) | ชื่อที่ใช้เข้าสู่ระบบ |

## 3.3 การสร้างผู้ใช้งานใหม่

<div class="procedure">

1. คลิกปุ่ม **"เพิ่มผู้ใช้งาน"** (Add User) ที่ด้านบนขวาของหน้า
2. กรอกข้อมูลในแบบฟอร์ม (ดูรายละเอียดในตาราง 3.1)
3. คลิกปุ่ม **"สุ่มรหัสผ่าน"** เพื่อให้ระบบสร้างรหัสผ่านเริ่มต้นโดยอัตโนมัติ
4. คลิก **"บันทึก"** เพื่อสร้างบัญชีผู้ใช้งาน
5. แจ้งชื่อผู้ใช้ (Username) และรหัสผ่านเริ่มต้นให้กับผู้ใช้งานใหม่

</div>

<div class="screenshot-placeholder">
[รูปที่ 3.2: แบบฟอร์มสร้างผู้ใช้งานใหม่]
</div>

**ตาราง 3.1 — ฟิลด์ในแบบฟอร์มสร้างผู้ใช้งาน**

| ฟิลด์ | จำเป็น | คำอธิบาย | ตัวอย่าง |
|-------|:------:|---------|---------|
| Username | ✓ | ชื่อเข้าสู่ระบบ (ภาษาอังกฤษ ไม่มีช่องว่าง) | `john.doe` |
| Password | ✓ | รหัสผ่านเริ่มต้น (ใช้ปุ่มสุ่มได้) | |
| ชื่อ-นามสกุล (Full Name) | ✓ | ชื่อแสดงในระบบ | `John Doe` |
| อีเมล | ✓ | อีเมลติดต่อ | `john@company.com` |
| บทบาท (Role) | ✓ | เลือกจากรายการ | Sale |
| แผนก (Department) | | แผนกที่สังกัด | Freight |
| สถานะ (Is Active) | ✓ | เปิด/ปิดการใช้งาน | เปิดใช้งาน |

!!! warning "ข้อสำคัญ"
    ระบบจะบังคับให้ผู้ใช้งานใหม่ **เปลี่ยนรหัสผ่านทันที** เมื่อเข้าสู่ระบบครั้งแรก ผู้ดูแลระบบต้องแจ้งรหัสผ่านเริ่มต้นให้ผู้ใช้งานทราบ

---

## 3.4 การแก้ไขข้อมูลผู้ใช้งาน

<div class="procedure">

1. ค้นหาผู้ใช้งานที่ต้องการแก้ไข
2. คลิกปุ่ม **"แก้ไข"** (Edit) หรือไอคอนดินสอ ในแถวของผู้ใช้งานนั้น
3. แก้ไขข้อมูลที่ต้องการ
4. คลิก **"บันทึก"**

</div>

**รายการที่สามารถแก้ไขได้:**
- ชื่อ-นามสกุล
- อีเมล
- บทบาท (Role)
- แผนก
- สถานะการใช้งาน (เปิด/ปิด)

!!! note "หมายเหตุ"
    **ไม่สามารถแก้ไข Username** ของผู้ใช้งานที่สร้างแล้ว หากต้องการเปลี่ยนชื่อผู้ใช้ต้องสร้างบัญชีใหม่และปิดการใช้งานบัญชีเดิม

---

## 3.5 การรีเซ็ตรหัสผ่าน

ในกรณีที่ผู้ใช้งานลืมรหัสผ่านหรือต้องการรีเซ็ต:

<div class="procedure">

1. เปิดหน้าแก้ไขผู้ใช้งาน (ดูข้อ 3.4)
2. คลิกปุ่ม **"สุ่มรหัสผ่านใหม่"**
3. บันทึกรหัสผ่านใหม่ที่ระบบสร้างให้
4. คลิก **"บันทึก"**
5. แจ้งรหัสผ่านใหม่ให้ผู้ใช้งาน — ระบบจะบังคับเปลี่ยนรหัสผ่านอีกครั้งเมื่อเข้าสู่ระบบ

</div>

---

## 3.6 การปิดการใช้งานบัญชี

<div class="procedure">

1. เปิดหน้าแก้ไขผู้ใช้งาน
2. ปิด Toggle **"Is Active"**
3. คลิก **"บันทึก"**

</div>

เมื่อปิดการใช้งาน ผู้ใช้งานนั้นจะ **ไม่สามารถเข้าสู่ระบบได้** แต่ข้อมูลยังคงอยู่ในระบบ

!!! danger "ข้อควรระวัง"
    ห้ามลบบัญชีผู้ดูแลระบบคนสุดท้ายออกจากระบบ เนื่องจากจะทำให้ไม่มีผู้มีสิทธิ์บริหารจัดการระบบ

---

## 3.7 การจัดการแผนก (Department)

แผนกใช้สำหรับจัดกลุ่มผู้ใช้งาน ผู้ดูแลระบบสามารถสร้างและจัดการแผนกได้ผ่านระบบ

**วิธีสร้างแผนกใหม่:**

<div class="procedure">

1. ในหน้า User Management คลิกที่ปุ่ม **"จัดการแผนก"**
2. คลิก **"เพิ่มแผนก"** (Add Department)
3. กรอกชื่อแผนก
4. คลิก **"บันทึก"**

</div>

---

## 3.8 โครงสร้างบทบาท (Role Structure)

### 3.8.1 Superadmin

- มีสิทธิ์สูงสุดในระบบ
- เข้าถึงข้อมูลและการตั้งค่าของ **ทุกบริษัท** ในระบบ
- สามารถสร้างผู้ดูแลระบบ (Admin) ให้กับบริษัทต่าง ๆ ได้
- เป็นบทบาทที่สงวนไว้สำหรับทีมเทคนิคหรือผู้ให้บริการระบบ

### 3.8.2 Admin

- มีสิทธิ์บริหารจัดการเต็มรูปแบบ **ภายในบริษัทของตนเอง**
- ไม่สามารถเข้าถึงข้อมูลของบริษัทอื่น
- สามารถสร้างผู้ใช้งาน Sale และ Admin รายอื่นได้

### 3.8.3 Sale

- ดูและค้นหาอัตราค่าระวางได้
- ส่งออกข้อมูลอัตราค่าระวางได้
- ไม่สามารถเข้าถึงการตั้งค่าระบบใด ๆ ได้

!!! tip "แนวปฏิบัติที่ดี"
    กำหนดจำนวน Admin ให้น้อยที่สุดเท่าที่จำเป็น และมอบบทบาท Sale ให้กับผู้ใช้งานทั่วไปเพื่อหลักการ Least Privilege

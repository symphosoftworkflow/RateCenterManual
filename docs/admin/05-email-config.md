# บทที่ 5 — การตั้งค่าอีเมล

*DOC-ADM-001 v1.0 | คู่มือผู้ดูแลระบบ*

---

## 5.1 ภาพรวม

ระบบดึงข้อมูล Rate Sheet จากอีเมลโดยผ่านโปรโตคอล **IMAP** (Internet Message Access Protocol) ผู้ดูแลระบบต้องตั้งค่าข้อมูลการเชื่อมต่ออีเมลก่อนที่ระบบจะสามารถดึงข้อมูลได้

**สิทธิ์การเข้าถึง:** Admin และ Superadmin

---

## 5.2 การตั้งค่า IMAP Server

### 5.2.1 เข้าสู่หน้าตั้งค่าอีเมล

<div class="procedure" markdown="block">

1. คลิกเมนู **Email Configuration** ในแถบนำทางด้านซ้าย
2. ระบบแสดงหน้าการตั้งค่าอีเมลปัจจุบัน (หากมีการตั้งค่าแล้ว) หรือแบบฟอร์มสำหรับตั้งค่าใหม่

</div>

### 5.2.2 กรอกข้อมูลการเชื่อมต่อ

| ฟิลด์ | จำเป็น | คำอธิบาย | ค่าตัวอย่าง |
|-------|:------:|---------|-----------|
| IMAP Server | ✓ | ชื่อโฮสต์ของ IMAP server | `imap.gmail.com` |
| Port | ✓ | หมายเลขพอร์ต | `993` (SSL) |
| Username | ✓ | อีเมลที่ใช้รับ Rate Sheet | `rates@company.com` |
| Password | ✓ | รหัสผ่านอีเมล | |
| Fetch Interval (นาที) | ✓ | ความถี่ในการดึงอีเมลอัตโนมัติ | `15` |
| Days Back | ✓ | ย้อนหลังกี่วันในการค้นหาอีเมล | `3` |
| Is Active | ✓ | เปิด/ปิดการใช้งานการตั้งค่านี้ | เปิด |

### 5.2.3 ทดสอบการเชื่อมต่อ

<div class="procedure" markdown="block">

1. หลังกรอกข้อมูลครบแล้ว คลิกปุ่ม **"ทดสอบการเชื่อมต่อ"** (Test Connection)
2. รอสักครู่ ระบบจะทดสอบ IMAP และแสดงผล
3. หากสำเร็จ ระบบแสดง ✓ "เชื่อมต่อสำเร็จ"
4. หากล้มเหลว ระบบแสดงข้อความแจ้งสาเหตุ (ดูการแก้ไขปัญหาในบทที่ 12)

</div>

### 5.2.4 บันทึกการตั้งค่า

<div class="procedure" markdown="block">

1. เมื่อทดสอบสำเร็จแล้ว คลิก **"บันทึก"** (Save)
2. ระบบยืนยันการบันทึก

</div>

## 5.3 การดึงอีเมลด้วยตนเอง (Manual Fetch)

<div class="procedure" markdown="block">

1. ในหน้า Email Configuration คลิกปุ่ม **"เริ่มดึงอีเมล"** (Start Fetch)
2. ระบบเริ่มต้นกระบวนการดึงอีเมลและแสดงความคืบหน้า
3. รอจนกระบวนการเสร็จสมบูรณ์
4. ระบบแสดงสรุปผล: จำนวนอีเมลที่ดึงมา, ไฟล์แนบที่บันทึก

</div>

<div class="screenshot-placeholder" markdown="block">
[รูปที่ 5.2: แถบความคืบหน้าการดึงอีเมล]
</div>

!!! note "หมายเหตุ"
    การดึงอีเมลอาจใช้เวลาหลายนาที ขึ้นอยู่กับจำนวนอีเมลใหม่ในกล่องจดหมาย ไม่ควรปิดหน้าต่างเบราว์เซอร์ระหว่างกระบวนการ

**การหยุดการดึงอีเมล:**

หากต้องการหยุดกระบวนการที่กำลังทำงานอยู่ คลิกปุ่ม **"หยุด"** (Stop Fetch) ระบบจะหยุดและบันทึกผลที่ดำเนินการไปแล้ว

---

## 5.4 การตั้งเวลาดึงอีเมลอัตโนมัติ (Scheduled Fetch)

ระบบสามารถดึงอีเมลโดยอัตโนมัติตามช่วงเวลาที่กำหนด

### 5.4.1 เปิดการดึงอีเมลอัตโนมัติ

<div class="procedure" markdown="block">

1. ในหน้า Email Configuration ตรวจสอบว่า `Fetch Interval` ตั้งค่าถูกต้องแล้ว
2. คลิกปุ่ม **"เปิดการดึงอีเมลอัตโนมัติ"** (Start Schedule)
3. ระบบยืนยันการเปิดใช้งานและแสดงสถานะ "กำลังทำงาน"

</div>

### 5.4.2 ปิดการดึงอีเมลอัตโนมัติ

<div class="procedure" markdown="block">

1. คลิกปุ่ม **"ปิดการดึงอีเมลอัตโนมัติ"** (Stop Schedule)
2. ระบบยืนยันการปิดใช้งาน

</div>

### 5.4.3 ตรวจสอบสถานะ

| สถานะ | ความหมาย |
|-------|---------|
| กำลังทำงาน (Running) | ระบบกำลังดึงอีเมลในขณะนี้ |
| รอรอบถัดไป (Scheduled) | กำหนดการดึงอีเมลรอบถัดไปอยู่ |
| หยุดทำงาน (Stopped) | ไม่มีการดึงอีเมลอัตโนมัติ |

---

## 5.5 ข้อมูลสถิติ

หน้า Email Configuration แสดงข้อมูลสถิติ:

| รายการ | คำอธิบาย |
|--------|---------|
| จำนวนอีเมลทั้งหมด | อีเมลที่ดึงมาสะสมในระบบ |
| อีเมลล่าสุด | เวลาที่ดึงอีเมลล่าสุด |
| สถานะการดึงอีเมลอัตโนมัติ | เปิด/ปิด |

---

## 5.6 การแก้ไขปัญหาเบื้องต้น

| ปัญหา | สาเหตุที่พบบ่อย | แนวทางแก้ไข |
|-------|----------------|------------|
| เชื่อมต่อไม่สำเร็จ | ข้อมูลเซิร์ฟเวอร์ผิด | ตรวจสอบ hostname และ port |
| Authentication Failed | รหัสผ่านผิด | ตรวจสอบรหัสผ่านหรือสร้าง App Password |
| Connection Timeout | ไฟร์วอลล์บล็อก | ตรวจสอบว่า port 993 เปิดอยู่ |
| ไม่พบอีเมลใหม่ | Days Back น้อยเกินไป | เพิ่มค่า Days Back |
| ดึงอีเมลซ้ำ | ระบบตรวจสอบจาก message_id | ไม่ใช่ปัญหา — ระบบจัดการ dedup อัตโนมัติ |

!!! tip "เคล็ดลับสำหรับ Gmail"
    Gmail ต้องเปิดใช้งาน **IMAP** ในการตั้งค่าบัญชีก่อน และหาก 2-Factor Authentication เปิดอยู่ ต้องสร้าง **App Password** จาก Google Account Settings แทนการใช้รหัสผ่านปกติ

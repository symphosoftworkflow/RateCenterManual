## 1. วัตถุประสงค์

เอกสารฉบับนี้จัดทำขึ้นเพื่อเป็นแนวทางการปฏิบัติงานสำหรับ **ผู้ดูแลระบบ (Administrator)** และ **ผู้ดูแลระบบสูงสุด (Superadministrator)** ในการติดตั้ง กำหนดค่า บริหารจัดการ และบำรุงรักษาระบบ RateSheetExtractor

---

## 2. ขอบเขต

คู่มือนี้ครอบคลุมหัวข้อต่อไปนี้:

- ภาพรวมสถาปัตยกรรมระบบและส่วนประกอบหลัก
- ข้อกำหนดระบบและการเข้าถึง
- การจัดการผู้ใช้งานและโครงสร้างบทบาท
- การจัดการข้อมูลบริษัท (สำหรับ Superadmin เท่านั้น)
- การตั้งค่าเซิร์ฟเวอร์อีเมลและแหล่งข้อมูล
- การตรวจสอบและอนุมัติข้อมูลอัตราค่าระวาง
- การบำรุงรักษาและการติดตามสถานะระบบ

**ขอบเขตที่ไม่ครอบคลุม:** การพัฒนาซอฟต์แวร์ การปรับแต่ง Parser และการดูแลโครงสร้างพื้นฐาน (Infrastructure) ซึ่งอยู่ในขอบเขตของฝ่ายเทคนิค

---

## 3. กลุ่มผู้ใช้เอกสาร

| บทบาท | คำอธิบาย |
|-------|-----------|
| **Superadmin** | ผู้ดูแลระบบสูงสุด มีสิทธิ์เข้าถึงทุกฟังก์ชันของทุกบริษัทในระบบ |
| **Admin** | ผู้ดูแลระบบระดับบริษัท มีสิทธิ์เต็มในขอบเขตบริษัทของตนเอง |

---

## 4. บทนิยามและคำย่อ

| คำ / คำย่อ | ความหมาย |
|-----------|----------|
| **Rate Sheet** | เอกสารอัตราค่าระวางสินค้าทางทะเลที่ส่งโดยสายเรือ |
| **Parser** | โปรแกรมวิเคราะห์ที่แยกข้อมูลออกจากเอกสาร Rate Sheet โดยอัตโนมัติ |
| **POL** | Port of Loading — ท่าเรือต้นทาง |
| **POD** | Port of Discharge — ท่าเรือปลายทาง |
| **IMAP** | Internet Message Access Protocol — โปรโตคอลสำหรับรับอีเมล |
| **Parse** | กระบวนการวิเคราะห์และแยกข้อมูลจากเอกสาร |
| **Surcharge** | ค่าธรรมเนียมเพิ่มเติมนอกจากอัตราค่าระวางพื้นฐาน |
| **T/T** | Transit Time — ระยะเวลาการขนส่ง (วัน) |
| **F/T** | Free Time — ระยะเวลาปลอดค่าใช้จ่าย (วัน) |
| **JWT** | JSON Web Token — ข้อมูลยืนยันตัวตนในรูปแบบ Token |
| **CRUD** | Create, Read, Update, Delete — การดำเนินการพื้นฐานกับข้อมูล |
| **Job Log** | บันทึกการทำงานของระบบ |
| **VSE** | Very Small Entity — หน่วยงานขนาดเล็กมาก (ตามนิยาม ISO/IEC 29110) |

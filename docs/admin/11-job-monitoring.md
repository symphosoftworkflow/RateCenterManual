# บทที่ 11 — การติดตาม Job Logs

*DOC-ADM-001 v1.0 | คู่มือผู้ดูแลระบบ*

---

## 11.1 ภาพรวม

**Job Logs** คือบันทึกประวัติการทำงานของระบบทั้งหมด ผู้ดูแลระบบสามารถติดตามสถานะของกระบวนการต่าง ๆ เช่น การดึงอีเมล การวิเคราะห์ข้อมูล และการอนุมัติ

**สิทธิ์การเข้าถึง:** Admin และ Superadmin

---

## 11.3 ประเภทของ Job

| ประเภท | คำอธิบาย |
|--------|---------|
| `email_fetch` | การดึงอีเมลจาก IMAP server |
| `parse` | การวิเคราะห์ข้อมูลจากไฟล์แนบ |
| `approval` | การอนุมัติหรือปฏิเสธข้อมูล |

---

## 11.4 สถานะของ Job

| สถานะ | สี | ความหมาย |
|-------|---|---------|
| `running` | 🔵 น้ำเงิน | กำลังทำงานอยู่ |
| `completed` | 🟢 เขียว | เสร็จสมบูรณ์ |
| `failed` | 🔴 แดง | ล้มเหลว มีข้อผิดพลาด |

---

## 11.5 การกรองและค้นหา Job Logs

<div class="procedure">

1. ใช้ตัวกรอง **ประเภท Job** (Job Type) เพื่อดูเฉพาะประเภทที่ต้องการ
2. ใช้ตัวกรอง **สถานะ** (Status) เพื่อดูเฉพาะ Job ที่ล้มเหลว เป็นต้น
3. ใช้ **การแบ่งหน้า** (Pagination) เพื่อดู Job เก่ากว่า

</div>

---

## 11.6 การดูรายละเอียด Job

<div class="procedure">

1. คลิกที่แถวของ Job ที่ต้องการดูรายละเอียด
2. ระบบแสดง JSON Details ของ Job นั้น ซึ่งมีข้อมูล:
   - จำนวนอีเมลที่ดึง/วิเคราะห์
   - ชื่อไฟล์ที่ประมวลผล
   - ข้อความ Error (กรณีล้มเหลว)

</div>

## 11.7 การแปลความหมายของ Job Logs

### 11.7.1 Email Fetch สำเร็จ

```
{
  "emails_fetched": 5,
  "attachments_saved": 8,
  "duration_seconds": 45
}
```

หมายความว่า: ดึงอีเมล 5 ฉบับ บันทึกไฟล์แนบ 8 ไฟล์ ใช้เวลา 45 วินาที

### 11.7.2 Parse สำเร็จ

```
{
  "source_name": "COSCO",
  "rows_parsed": 42,
  "email_id": 123
}
```

หมายความว่า: วิเคราะห์ COSCO ได้ 42 แถว รอการอนุมัติ

### 11.7.3 Job ล้มเหลว

```
{
  "error": "Parser error: unexpected format on row 15",
  "source_name": "HMM",
  "email_id": 124
}
```

หมายความว่า: HMM Parser พบข้อผิดพลาดที่แถว 15 — ควรดาวน์โหลดและตรวจสอบไฟล์แนบ

## 11.8 การติดตามสถานะจาก Dashboard

หน้า **Dashboard** แสดงสถิติภาพรวมที่ควรตรวจสอบสม่ำเสมอ:

| รายการ | ความหมาย |
|--------|---------|
| อีเมลทั้งหมด | จำนวนอีเมลที่ดึงมาสะสม |
| รอการอนุมัติ | จำนวนที่ต้องการการตรวจสอบ |
| ล้มเหลว | จำนวนที่ต้องการการแก้ไข |
| อัตราค่าระวางทั้งหมด | จำนวนแถวที่อนุมัติแล้ว |

!!! tip "เคล็ดลับ"
    ตรวจสอบ Dashboard และ Job Logs ทุกเช้าวันทำการ เพื่อให้แน่ใจว่ากระบวนการดำเนินไปอย่างราบรื่น

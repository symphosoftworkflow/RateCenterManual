# บทที่ 9 — การอัปเดตข้อมูล Routing

*DOC-ADM-001 v1.0 | คู่มือผู้ดูแลระบบ*

---

## 9.1 ภาพรวม

**Routing Update** คือการอัปเดตข้อมูลเส้นทางการขนส่ง ได้แก่ ระยะเวลาขนส่ง (T/T), ระยะเวลาปลอดค่าใช้จ่าย (F/T), และข้อมูลเส้นทาง (Routing) ให้กับอัตราค่าระวางที่บันทึกไว้ในระบบ

ข้อมูล Routing มาจากไฟล์ Excel ที่อัปโหลดในรูปแบบไฟล์ ZIP

**สิทธิ์การเข้าถึง:** Admin และ Superadmin

---

## 9.2 การเตรียมไฟล์ Routing

### 9.2.1 รูปแบบไฟล์

ไฟล์ Routing ต้องอยู่ในรูปแบบต่อไปนี้:
- ประเภทไฟล์: **ZIP** ที่บรรจุไฟล์ **Excel (.xlsx)**
- Excel ต้องมีคอลัมน์ตามที่ระบบกำหนด

### 9.2.2 คอลัมน์ที่จำเป็นใน Excel

| คอลัมน์ | คำอธิบาย |
|---------|---------|
| Carrier | รหัสสายเรือ (เช่น COSCO, HMM) |
| POL | ท่าเรือต้นทาง |
| POD | ท่าเรือปลายทาง |
| T/T | Transit Time (วัน) |
| F/T | Free Time (วัน) |
| Routing | เส้นทางการขนส่ง |

---

## 9.3 การอัปโหลดและดูตัวอย่าง

<div class="procedure" markdown="block">

1. คลิกเมนู **Routing Updates** ในแถบนำทาง
2. คลิกปุ่ม **"อัปโหลดไฟล์"** (Upload ZIP)
3. เลือกไฟล์ ZIP ที่เตรียมไว้
4. ระบบประมวลผลและแสดงหน้า **Preview** ว่าจะจับคู่กับอัตราค่าระวางใด

</div>

<div class="screenshot-placeholder" markdown="block">
[รูปที่ 9.1: หน้าจอ Routing Updates — Preview ผลการจับคู่]
</div>

**ข้อมูลที่แสดงใน Preview:**

| คอลัมน์ | คำอธิบาย |
|---------|---------|
| สายเรือ | Carrier |
| POL → POD | เส้นทางที่จับคู่ได้ |
| T/T ปัจจุบัน | ค่า T/T ในฐานข้อมูลปัจจุบัน |
| T/T ใหม่ | ค่า T/T จากไฟล์ที่อัปโหลด |
| จำนวนแถวที่จะอัปเดต | จำนวนอัตราค่าระวางที่ได้รับผลกระทบ |

---

## 9.4 การนำข้อมูล Routing ไปใช้

<div class="procedure" markdown="block">

1. ตรวจสอบข้อมูล Preview ว่าถูกต้อง
2. คลิกปุ่ม **"นำไปใช้"** (Apply)
3. ยืนยันการดำเนินการ
4. ระบบอัปเดตข้อมูล T/T, F/T และ Routing ในตาราง `parsed_rate_rows`

</div>

!!! warning "คำเตือน"
    การ Apply จะอัปเดตข้อมูลโดยตรงในฐานข้อมูล ไม่สามารถย้อนกลับได้ง่าย ควรตรวจสอบ Preview ให้ละเอียดก่อนดำเนินการ

---

## 9.5 การดูสถิติและประวัติการอัปเดต

<div class="procedure" markdown="block">

1. ในหน้า Routing Updates คลิกปุ่ม **"สถิติ"** (Stats)
2. ระบบแสดงประวัติการอัปโหลดและจำนวนแถวที่อัปเดต

</div>

---

## 9.6 การล้างข้อมูล Routing

<div class="procedure" markdown="block">

1. คลิกปุ่ม **"ล้างข้อมูล Routing"** (Clear)
2. ยืนยันการดำเนินการ

</div>

!!! danger "ข้อควรระวังสูง"
    การล้างข้อมูล Routing จะลบข้อมูล T/T, F/T, และ Routing ออกจากอัตราค่าระวางทั้งหมด ดำเนินการด้วยความระมัดระวัง

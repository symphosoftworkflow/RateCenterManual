## 2.1 ข้อกำหนดสำหรับผู้ดูแลระบบ

### 2.1.1 ความรู้และทักษะที่จำเป็น

ผู้ดูแลระบบควรมีความรู้และทักษะพื้นฐานดังต่อไปนี้:

| ด้าน | ระดับที่จำเป็น |
|------|--------------|
| การใช้งานคอมพิวเตอร์และเบราว์เซอร์ | พื้นฐาน |
| ความเข้าใจเกี่ยวกับอีเมล IMAP/SMTP | พื้นฐาน |
| การอ่านข้อมูลอัตราค่าระวาง (Rate Sheet) | ปานกลาง |
| ความเข้าใจโครงสร้างองค์กร (บริษัท แผนก) | พื้นฐาน |

### 2.1.2 สิทธิ์การเข้าถึงที่จำเป็น

| รายการ | Admin | Superadmin |
|--------|:-----:|:----------:|
| บัญชีผู้ใช้งานระบบบทบาท Admin หรือ Superadmin | ✓ | ✓ |
| ข้อมูล IMAP Server (host, port, username, password) | ✓ | ✓ |
| URL ระบบ RateSheetExtractor | ✓ | ✓ |

## 2.2 ข้อกำหนดสำหรับเครื่องผู้ใช้งาน (Client)

ระบบทำงานผ่านเบราว์เซอร์ ไม่จำเป็นต้องติดตั้งซอฟต์แวร์พิเศษ

### 2.2.1 เบราว์เซอร์ที่รองรับ

| เบราว์เซอร์ | เวอร์ชันขั้นต่ำ | หมายเหตุ |
|------------|----------------|---------|
| Google Chrome | 110 ขึ้นไป | **แนะนำ** |
| Microsoft Edge | 110 ขึ้นไป | รองรับ |
| Mozilla Firefox | 110 ขึ้นไป | รองรับ |
| Apple Safari | 16 ขึ้นไป | รองรับ |

!!! warning "คำเตือน"
    ไม่รองรับ Internet Explorer ทุกรุ่น

### 2.2.2 ข้อกำหนดฮาร์ดแวร์ขั้นต่ำ

| รายการ | ข้อกำหนดขั้นต่ำ |
|--------|----------------|
| หน่วยความจำ (RAM) | 4 GB |
| ความละเอียดหน้าจอ | 1280 × 768 พิกเซล ขึ้นไป |
| ความเร็วอินเทอร์เน็ต | 10 Mbps ขึ้นไป |
| ระบบปฏิบัติการ | Windows 10+, macOS 12+, Ubuntu 20.04+ |

### 2.2.3 การตั้งค่าเบราว์เซอร์

เพื่อให้ระบบทำงานได้อย่างถูกต้อง ให้ตรวจสอบการตั้งค่าดังนี้:

- **เปิดใช้ JavaScript:** เปิดใช้งาน (เปิดโดยค่าเริ่มต้น)
- **เปิดใช้ Cookies:** อนุญาต Cookie จาก domain ของระบบ
- **การดาวน์โหลดไฟล์:** อนุญาตให้เบราว์เซอร์ดาวน์โหลดไฟล์ Excel (.xlsx)
- **Popup:** อนุญาต popup หากระบบต้องการแสดงหน้าต่างเพิ่มเติม

## 2.3 ข้อกำหนดการเชื่อมต่ออีเมล IMAP

เพื่อให้ระบบสามารถดึงอีเมลได้ ต้องมีข้อมูลการเชื่อมต่อ IMAP ดังนี้:

| รายการ | ตัวอย่าง | หมายเหตุ |
|--------|---------|---------|
| IMAP Server Hostname | `imap.gmail.com` | สอบถามจาก IT หรือผู้ให้บริการอีเมล |
| IMAP Port | `993` | โดยทั่วไป 993 (SSL) หรือ 143 (STARTTLS) |
| Username (อีเมล) | `rates@company.com` | อีเมลที่รับ Rate Sheet |
| Password | `••••••••` | รหัสผ่านบัญชีอีเมล |
| SSL/TLS | เปิดใช้งาน | Port 993 ใช้ SSL |

!!! tip "เคล็ดลับ"
    หากใช้ Gmail ต้องเปิดใช้ **"Less secure app access"** หรือสร้าง **App Password** แทนการใช้รหัสผ่านบัญชีหลัก

## 2.4 การเข้าสู่ระบบครั้งแรก (Initial Setup)

เมื่อระบบเริ่มต้นใช้งาน ให้ดำเนินการตามลำดับดังนี้:

<div class="procedure">

1. **เข้าสู่ระบบด้วยบัญชี Admin หรือ Superadmin** ที่ได้รับจากผู้ดูแลโครงสร้างพื้นฐาน
2. **เปลี่ยนรหัสผ่านทันที** ตามนโยบายความปลอดภัย (ดูบทที่ 3)
3. **สร้างผู้ใช้งาน** ให้กับทีมงาน (ดูบทที่ 3)
4. **ตั้งค่า IMAP** ให้ถูกต้องตามข้อมูลอีเมลที่ใช้รับ Rate Sheet (ดูบทที่ 5)
5. **กำหนด Source Email** ให้ครบถ้วนสำหรับทุกสายเรือที่ต้องการ (ดูบทที่ 6)
6. **กำหนดนิยาม Surcharge** ให้ครบตามที่องค์กรต้องการ (ดูบทที่ 7)
7. **ตั้งค่าอีเมลแจ้งเตือน** เพื่อรับการแจ้งเตือนเมื่อมีข้อมูลใหม่ (ดูบทที่ 10)
8. **ทดสอบการดึงอีเมล** ด้วยตนเองครั้งแรก (ดูบทที่ 5)

</div>

## 2.5 นโยบายความปลอดภัย

### 2.5.1 นโยบายรหัสผ่าน

| เงื่อนไข | ข้อกำหนด |
|---------|---------|
| ความยาวขั้นต่ำ | 8 ตัวอักษร |
| ตัวพิมพ์ใหญ่ | อย่างน้อย 1 ตัว |
| ตัวพิมพ์เล็ก | อย่างน้อย 1 ตัว |
| ตัวเลข | อย่างน้อย 1 ตัว |
| อักขระพิเศษ | อย่างน้อย 1 ตัว (เช่น `!@#$%^&*`) |
| การเปลี่ยนรหัสผ่าน | ต้องเปลี่ยนเมื่อเข้าสู่ระบบครั้งแรก |

### 2.5.2 การจัดการ Session

- **Token** มีอายุการใช้งาน — หากหมดอายุจะต้องเข้าสู่ระบบใหม่
- ห้ามแชร์บัญชีผู้ใช้งานระหว่างบุคคล
- ควร **ออกจากระบบ (Logout)** เมื่อเสร็จสิ้นการใช้งาน โดยเฉพาะบนเครื่องสาธารณะ

!!! danger "ข้อควรระวัง"
    ห้ามจัดเก็บรหัสผ่าน IMAP ในไฟล์ข้อความหรือส่งทางอีเมลโดยไม่เข้ารหัส ข้อมูล IMAP ที่บันทึกในระบบได้รับการเข้ารหัสในฐานข้อมูล

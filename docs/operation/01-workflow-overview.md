กระบวนการทำงานของระบบ RateSheetExtractor แบ่งออกเป็น **7 ขั้นตอน** ตามวงจรชีวิตของข้อมูล:

│          │                                                 │
│          ▼                                                 │

│          │  จัดเก็บใน raw_emails                           │
│          ▼                                                 │
│  [3] Python Parser วิเคราะห์ไฟล์แนบ                       │

## 1.2 รายละเอียดแต่ละขั้นตอน

### ขั้นตอนที่ 1 — สายเรือส่งอีเมล

สายเรือส่ง Rate Sheet มาทางอีเมลในรูปแบบไฟล์แนบ (PDF, Excel, หรือ txt) ไปยังกล่องจดหมายที่กำหนดไว้

**ผู้รับผิดชอบ:** สายเรือ (ไม่ต้องดำเนินการในฝั่งระบบ)

---

### ขั้นตอนที่ 2 — ระบบดึงอีเมล

ระบบเชื่อมต่อกับ IMAP server และดึงอีเมลใหม่ที่ตรงกับ Source Email ที่กำหนดไว้

**โหมดการทำงาน:**
- **อัตโนมัติ:** ทำงานตาม Fetch Interval ที่ตั้งไว้ (เช่น ทุก 15 นาที)
- **ด้วยตนเอง:** เจ้าหน้าที่กดปุ่ม "Start Fetch" ในหน้า Email Configuration

**ผลลัพธ์:** อีเมลและไฟล์แนบบันทึกใน `raw_emails` และ `email_attachments`

---

### ขั้นตอนที่ 3 — Python Parser วิเคราะห์

ระบบเรียก Python Parser ที่เหมาะสมตาม Source Name และวิเคราะห์ไฟล์แนบโดยอัตโนมัติ

**Parser รองรับ:** COSCO, ESL, HMM, KMTC, PIL, ZIM, CKLINE, SMLINE, TSLINE, RCL, IAL, JJS, SINOKOR, SITC, YANGMING

**ผลลัพธ์:**
- สำเร็จ: บันทึกผลใน `parse_review_queue` สถานะ `pending_approval`
- ล้มเหลว: บันทึกใน `parse_review_queue` สถานะ `parse_failed`

---

### ขั้นตอนที่ 4 — ตรวจสอบและอนุมัติ

**ผู้รับผิดชอบ:** เจ้าหน้าที่ (Admin)

เจ้าหน้าที่ตรวจสอบผลการวิเคราะห์ใน **Parse Review Queue** และดำเนินการ:

| การดำเนินการ | ผลลัพธ์ |
|-------------|--------|
| อนุมัติ (Approve) | ข้อมูลย้ายไป `parsed_rate_rows` |
| ปฏิเสธ (Reject) | ข้อมูลถูกทำเครื่องหมาย Rejected |
| Reparse | ลบผลเดิมและวิเคราะห์ใหม่ |

---

### ขั้นตอนที่ 5 — บันทึกข้อมูล

ข้อมูลที่ได้รับการอนุมัติถูกบันทึกใน `parsed_rate_rows` พร้อมใช้งาน

---

### ขั้นตอนที่ 6 — ผู้ใช้งานค้นหา

ผู้ใช้งาน (Sale) เข้าถึงหน้า Rate Query เพื่อค้นหา ดู และส่งออกข้อมูล

---

### ขั้นตอนที่ 7 — นำไปใช้งาน

ผู้ใช้งานนำข้อมูลอัตราค่าระวางที่ได้ไปใช้ในการเสนอราคาและจัดการขนส่ง

---

## 1.3 ตารางสรุปผู้รับผิดชอบ

| ขั้นตอน | ผู้รับผิดชอบหลัก | เครื่องมือ |
|---------|----------------|----------|
| 1. สายเรือส่งอีเมล | สายเรือ | — |
| 2. ดึงอีเมล | ระบบ (อัตโนมัติ) / Admin (manual) | Email Configuration |
| 3. วิเคราะห์ | ระบบ (อัตโนมัติ) | Python Parser |
| 4. ตรวจสอบ/อนุมัติ | Admin | Job Logs → Parse Review |
| 5. บันทึก | ระบบ (อัตโนมัติ) | — |
| 6. ค้นหา | Sale / Admin | Rate Query |
| 7. ใช้งาน | Sale / ฝ่ายขาย | Excel |

## 1.4 ความถี่ของการปฏิบัติงาน

| กิจกรรม | ความถี่ |
|---------|--------|
| ตรวจสอบ Job Logs | ทุกวันทำการ ตอนเช้า |
| ตรวจสอบ Parse Review Queue | ทุกวันทำการ หรือเมื่อได้รับการแจ้งเตือน |
| ทดสอบการเชื่อมต่อ IMAP | สัปดาห์ละ 1 ครั้ง |
| ตรวจสอบผู้ใช้งาน | เดือนละ 1 ครั้ง |
| สำรองข้อมูล (Export) | เดือนละ 1 ครั้ง หรือตามนโยบายบริษัท |

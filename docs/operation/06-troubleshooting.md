# บทที่ 6 — การแก้ไขปัญหา

*DOC-OPR-001 v1.0 | คู่มือการปฏิบัติงาน*

---

## 6.1 หลักการวินิจฉัยปัญหา

เมื่อพบปัญหาในระบบ ให้ดำเนินการตามลำดับดังนี้:

```
[1] สังเกตอาการ
    │
    ▼
[2] ตรวจสอบ Job Logs เพื่อหา Error Message
    │
    ▼
[3] ค้นหาในตาราง Troubleshooting (บทนี้)
    │
    ├── พบแนวทาง → ดำเนินการแก้ไข
    │
    └── ไม่พบ → ส่งต่อทีมเทคนิค (บทที่ 7)
```

---

## 6.2 ปัญหาการเข้าสู่ระบบ

| อาการ | สาเหตุ | แนวทางแก้ไข |
|-------|--------|-----------|
| "Username หรือ Password ไม่ถูกต้อง" | กรอกข้อมูลผิด หรือ Caps Lock เปิดอยู่ | ตรวจสอบ Caps Lock และกรอกใหม่ |
| หน้าเข้าสู่ระบบไม่โหลด | URL ผิด หรืออินเทอร์เน็ตมีปัญหา | ตรวจสอบ URL และการเชื่อมต่อ |
| เข้าได้แต่ถูกกระเด้งออกทันที | Token หมดอายุ | ปิดแท็บและเปิดใหม่ แล้วเข้าสู่ระบบอีกครั้ง |
| บัญชีถูกระงับ | ผู้ดูแลปิดบัญชี | ติดต่อผู้ดูแลระบบ |

---

## 6.3 ปัญหาการดึงอีเมล

| อาการ / Error | สาเหตุ | แนวทางแก้ไข |
|--------------|--------|-----------|
| `Authentication Failed` | รหัสผ่าน IMAP ผิด หรือ App Password หมดอายุ | อัปเดตรหัสผ่านในหน้า Email Configuration |
| `Connection refused / timeout` | IMAP Server ไม่ตอบสนอง หรือ Firewall บล็อก | ตรวจสอบ hostname, port และ Firewall |
| `SSL Certificate error` | Certificate หมดอายุหรือไม่ถูกต้อง | แจ้งทีมเทคนิค |
| ดึงได้ 0 อีเมล | ไม่มีอีเมลใหม่ใน `days_back` วันที่ผ่านมา | เพิ่มค่า Days Back ชั่วคราว |
| กระบวนการค้างไม่เสร็จ | ปัญหาเครือข่ายชั่วคราว | คลิก "Stop" แล้วรอ 5 นาที แล้วลองใหม่ |

---

## 6.4 ปัญหาการวิเคราะห์ข้อมูล (Parser)

| อาการ | สาเหตุ | แนวทางแก้ไข |
|-------|--------|-----------|
| Parse Failed สำหรับสายเรือหนึ่ง | รูปแบบ Rate Sheet เปลี่ยน | ดาวน์โหลดไฟล์แนบ → ตรวจสอบ → แจ้งทีมเทคนิค |
| ผล Pending แต่ข้อมูลดูผิด (POL/POD เป็นตัวเลข) | Parser อ่านแถวหัวตารางผิด | ลอง Reparse ก่อน ถ้ายังผิดแจ้งทีมเทคนิค |
| ข้อมูล 0 แถว แต่ไม่มี Error | Rate Sheet ว่างเปล่าหรือรูปแบบไม่รองรับ | ตรวจสอบไฟล์แนบ และแจ้งทีมเทคนิค |
| Parser ไม่รู้จักสายเรือ | Source Name ผิดพลาด | ตรวจสอบ Source Email → แก้ไข Source Name |

---

## 6.5 ปัญหาการแสดงผลและค้นหา

| อาการ | สาเหตุ | แนวทางแก้ไข |
|-------|--------|-----------|
| ค้นหาไม่พบข้อมูลทั้งที่อนุมัติแล้ว | เลือกเดือน/ปีไม่ตรง | ตรวจสอบเดือน/ปีที่เลือกในตัวกรอง |
| ดาวน์โหลด Excel แล้วไฟล์ว่าง | ไม่มีข้อมูลตรงเงื่อนไข | ผ่อนคลายตัวกรอง |
| ตัวอักษรใน Excel เป็นรหัส | Encoding ไม่ถูกต้อง | เปิดไฟล์โดยเลือก Encoding UTF-8 |
| หน้าค้างไม่ตอบสนอง | เครือข่ายมีปัญหา | รีเฟรชหน้าและลองใหม่ |

---

## 6.6 ขั้นตอนทั่วไปเมื่อพบปัญหาที่ไม่รู้จัก

<div class="procedure">

1. **บันทึก** ข้อความ Error ที่ปรากฏ (ถ่ายภาพหน้าจอ)
2. **จดบันทึก** ขั้นตอนที่ทำก่อนเกิดปัญหา
3. **ลองรีเฟรช** หน้าเว็บและดำเนินการใหม่
4. **ตรวจสอบ** Job Logs เพื่อดู Error Message เพิ่มเติม
5. **ลอง** ดำเนินการซ้ำอีกครั้ง (บางครั้งปัญหาชั่วคราวหายเอง)
6. หากยังพบปัญหา: **รวบรวมข้อมูล** และแจ้งทีมเทคนิค (ดูบทที่ 7)

</div>

## 6.7 รหัสข้อผิดพลาด HTTP ที่พบบ่อย

| รหัส | ความหมาย | การดำเนินการ |
|------|---------|------------|
| `401 Unauthorized` | Token หมดอายุ | ออกจากระบบแล้วเข้าสู่ระบบใหม่ |
| `403 Forbidden` | ไม่มีสิทธิ์เข้าถึง | ติดต่อผู้ดูแลระบบ |
| `404 Not Found` | ข้อมูลไม่พบ | ตรวจสอบว่าข้อมูลยังอยู่ในระบบ |
| `500 Internal Server Error` | ข้อผิดพลาดของ Server | แจ้งทีมเทคนิค พร้อม timestamp และขั้นตอนที่ทำ |
| `502 Bad Gateway` | Server ไม่ตอบสนอง | รอสักครู่แล้วลองใหม่ หากยังพบแจ้งทีมเทคนิค |

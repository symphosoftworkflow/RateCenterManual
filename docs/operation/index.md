## 1. วัตถุประสงค์

เอกสารฉบับนี้จัดทำขึ้นเพื่อกำหนด **ขั้นตอนปฏิบัติงานมาตรฐาน (Standard Operating Procedures — SOP)** สำหรับ **เจ้าหน้าที่ปฏิบัติงาน (Operator)** ในการดูแลและใช้งานระบบ RateSheetExtractor อย่างมีประสิทธิภาพและต่อเนื่อง

---

## 2. ขอบเขต

คู่มือนี้ครอบคลุมหัวข้อต่อไปนี้:

- ภาพรวมกระบวนการทำงานของระบบตั้งแต่ต้นถึงปลาย
- รายการตรวจสอบประจำวัน (Daily Checklist)
- ขั้นตอนการดึงข้อมูลอีเมล (Manual และ Automatic)
- กระบวนการตรวจสอบและอนุมัติข้อมูล
- การจัดตารางเวลาอัตโนมัติ
- การวินิจฉัยและแก้ไขปัญหาที่พบบ่อย
- ขั้นตอนการรายงานและส่งต่อปัญหา

**ขอบเขตที่ไม่ครอบคลุม:** การพัฒนาระบบ การแก้ไขโค้ด และการดูแลโครงสร้างพื้นฐาน

---

## 3. กลุ่มผู้ใช้เอกสาร

| บทบาท | คำอธิบาย |
|-------|-----------|
| **เจ้าหน้าที่ปฏิบัติงาน** | ผู้ดูแลระบบในงานประจำวัน (Admin) |
| **หัวหน้างาน** | ผู้รับผิดชอบกำกับดูแลการปฏิบัติงาน |
| **ทีมเทคนิค** | สำหรับอ้างอิงในกรณีแก้ไขปัญหา |

---

## 4. บทนิยามและคำย่อ

| คำ / คำย่อ | ความหมาย |
|-----------|----------|
| **SOP** | Standard Operating Procedure — ขั้นตอนปฏิบัติงานมาตรฐาน |
| **IMAP** | Internet Message Access Protocol — โปรโตคอลรับอีเมล |
| **Parse** | กระบวนการวิเคราะห์ข้อมูลจากเอกสาร |
| **Rate Sheet** | เอกสารอัตราค่าระวางจากสายเรือ |
| **POL/POD** | Port of Loading / Port of Discharge |
| **Job Log** | บันทึกการทำงานของระบบ |
| **Reparse** | การวิเคราะห์ข้อมูลใหม่อีกครั้ง |
| **Batch Approve** | การอนุมัติหลายรายการพร้อมกัน |
| **T/T** | Transit Time — ระยะเวลาขนส่ง |
| **Escalation** | การส่งต่อปัญหาให้ผู้รับผิดชอบในระดับที่สูงขึ้น |

# บทที่ 3 — การดึงข้อมูลอีเมล

*DOC-OPR-001 v1.0 | คู่มือการปฏิบัติงาน*

---

## 3.1 ภาพรวม

ระบบดึงอีเมล Rate Sheet จากเซิร์ฟเวอร์อีเมลผ่านโปรโตคอล IMAP มี **2 โหมด:**

| โหมด | เงื่อนไขการใช้งาน |
|------|----------------|
| **อัตโนมัติ (Scheduled)** | ใช้เป็นปกติ ระบบทำงานเองตาม Fetch Interval |
| **ด้วยตนเอง (Manual)** | ใช้เมื่อต้องการดึงอีเมลทันที หรือเมื่อระบบอัตโนมัติมีปัญหา |

---

## 3.2 ขั้นตอนการดึงอีเมลด้วยตนเอง (Manual Fetch)

### SOP-EMAIL-001: Manual Email Fetch

**วัตถุประสงค์:** ดึงอีเมล Rate Sheet ใหม่ทันทีโดยไม่รอรอบอัตโนมัติ

**ผู้รับผิดชอบ:** Admin

**ขั้นตอน:**

<div class="procedure" markdown="block">

1. เข้าสู่ระบบด้วยบัญชี Admin
2. คลิกเมนู **Email Configuration** ในแถบนำทาง
3. ตรวจสอบว่าการตั้งค่า IMAP ถูกต้อง (หากไม่แน่ใจ คลิก "ทดสอบการเชื่อมต่อ" ก่อน)
4. คลิกปุ่ม **"เริ่มดึงอีเมล"** (Start Fetch)
5. ระบบเริ่มกระบวนการและแสดงแถบความคืบหน้า
6. รอจนแถบความคืบหน้าเต็ม และระบบแสดงข้อความ "เสร็จสมบูรณ์"
7. ตรวจสอบสรุปผล: จำนวนอีเมลใหม่ที่ดึงมาและไฟล์แนบที่บันทึก

</div>

**เงื่อนไขสำเร็จ:** แถบความคืบหน้าเต็ม 100% และระบบแสดงสถิติสรุป

**เงื่อนไขล้มเหลว:** ระบบแสดงข้อความ Error หรือแถบหยุดกลางคัน → ดูบทที่ 6

## 3.3 การตรวจสอบผลการดึงอีเมล

หลังดึงอีเมลเสร็จ ให้ตรวจสอบดังนี้:

<div class="procedure" markdown="block">

1. คลิกเมนู **Job Logs**
2. ดูรายการ `email_fetch` ล่าสุด
3. ยืนยันว่าสถานะเป็น **completed** (สีเขียว)
4. คลิกดูรายละเอียดเพื่อดูจำนวนอีเมลที่ดึงมา

</div>

**ข้อมูลที่ควรตรวจสอบใน Job Log:**

```json
{
  "emails_fetched": 3,
  "attachments_saved": 5,
  "duration_seconds": 32
}
```

- `emails_fetched`: จำนวนอีเมลใหม่ที่ดึงมาได้
- `attachments_saved`: จำนวนไฟล์แนบที่บันทึก
- `duration_seconds`: ระยะเวลาที่ใช้

## 3.4 การดึงอีเมลอัตโนมัติ (Scheduled Fetch)

ระบบดึงอีเมลอัตโนมัติตาม **Fetch Interval** ที่กำหนดไว้ (ค่าเริ่มต้น 15 นาที)

### 3.4.1 ตรวจสอบสถานะระบบอัตโนมัติ

<div class="procedure" markdown="block">

1. เข้าหน้า **Email Configuration**
2. ดูส่วน "สถานะการดึงอีเมลอัตโนมัติ"
3. ยืนยันว่าสถานะแสดง "กำลังทำงาน" หรือ "รอรอบถัดไป"

</div>

| สถานะ | ความหมาย | การดำเนินการ |
|-------|---------|------------|
| กำลังทำงาน | ระบบกำลังดึงอีเมลอยู่ | รอให้เสร็จ |
| รอรอบถัดไป | ระบบทำงานปกติ รอเวลาถัดไป | ไม่ต้องดำเนินการ |
| หยุดทำงาน | ระบบอัตโนมัติปิดอยู่ | เปิดใช้งาน หรือดึงด้วยตนเอง |

### 3.4.2 เปิดระบบอัตโนมัติ (หากปิดอยู่)

<div class="procedure" markdown="block">

1. หน้า **Email Configuration** คลิกปุ่ม **"เปิดการดึงอีเมลอัตโนมัติ"** (Start Schedule)
2. ยืนยันการดำเนินการ
3. สถานะเปลี่ยนเป็น "รอรอบถัดไป"

</div>

## 3.5 กรณีพิเศษ — Rate Sheet เก่าย้อนหลัง

หากต้องการดึงอีเมล Rate Sheet ที่ส่งมาเกิน 3 วันที่ผ่านมา (เกินค่า Days Back ปัจจุบัน):

<div class="procedure" markdown="block">

1. เข้าหน้า **Email Configuration**
2. เพิ่มค่า **Days Back** ชั่วคราว (เช่น จาก 3 เป็น 30)
3. บันทึกการตั้งค่า
4. ดึงอีเมลด้วยตนเอง
5. หลังดึงเสร็จ ตั้งค่า **Days Back** คืนเป็นค่าเดิม

</div>

!!! warning "คำเตือน"
    การเพิ่ม Days Back มากเกินไปอาจทำให้ระบบดึงอีเมลเก่าจำนวนมาก และใช้เวลานาน รวมถึงอาจทำให้มีข้อมูลซ้ำกัน

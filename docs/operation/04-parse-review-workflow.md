# บทที่ 4 — การตรวจสอบและอนุมัติ

*DOC-OPR-001 v1.0 | คู่มือการปฏิบัติงาน*

---

## 4.1 ภาพรวม

กระบวนการตรวจสอบและอนุมัติเป็น **ด่านคุณภาพ (Quality Gate)** ก่อนที่ข้อมูลอัตราค่าระวางจะถูกนำไปใช้งาน เจ้าหน้าที่มีหน้าที่ยืนยันความถูกต้องของข้อมูลที่ระบบวิเคราะห์มาได้

---

## 4.2 SOP-REVIEW-001: การตรวจสอบและอนุมัติข้อมูล

**วัตถุประสงค์:** ตรวจสอบและอนุมัติข้อมูลอัตราค่าระวางที่ Parser วิเคราะห์แล้ว

**ผู้รับผิดชอบ:** Admin

**ความถี่:** ทุกครั้งที่ได้รับการแจ้งเตือน หรืออย่างน้อยวันละ 1 ครั้ง

### ขั้นตอน:

<div class="procedure" markdown="block">

1. คลิกเมนู **Job Logs** → แท็บ **"Parse Review"**
2. ตรวจสอบจำนวนรายการที่รอการอนุมัติ (Pending Approval)
3. สำหรับแต่ละรายการ: คลิก **"ดูอีเมล"** เพื่อดาวน์โหลดไฟล์แนบต้นฉบับ
4. เปรียบเทียบข้อมูลที่วิเคราะห์กับไฟล์ต้นฉบับ
5. หากถูกต้อง: คลิก **"อนุมัติ"** (Approve)
6. หากไม่ถูกต้อง: คลิก **"ปฏิเสธ"** (Reject) หรือ **"Reparse"**
7. ทำซ้ำจนรายการรอการอนุมัติหมด

</div>

---

## 4.3 เกณฑ์การตรวจสอบ

เจ้าหน้าที่ควรตรวจสอบรายการต่อไปนี้ก่อนอนุมัติ:

| รายการ | เกณฑ์ที่ยอมรับได้ |
|--------|----------------|
| POL (ท่าเรือต้นทาง) | ต้องเป็นชื่อท่าเรือที่ถูกต้อง ไม่ใช่รหัสหรือตัวเลข |
| POD (ท่าเรือปลายทาง) | ต้องเป็นชื่อท่าเรือที่ถูกต้อง |
| อัตราค่าระวาง | ต้องเป็นตัวเลขที่สมเหตุสมผล (ไม่ใช่ 0 หรือ ติดลบ โดยไม่มีเหตุผล) |
| วันหมดอายุ | ต้องอยู่ในช่วงเวลาที่สมเหตุสมผล |
| สายเรือ | ต้องตรงกับ Source Name ที่ระบุ |

---

## 4.4 การตัดสินใจในแต่ละกรณี

### กรณีที่ 1 — ข้อมูลถูกต้องทั้งหมด

→ คลิก **"อนุมัติ"** หรือใช้ **"Batch Approve"**

### กรณีที่ 2 — ข้อมูลบางส่วนผิด แต่ Parser อาจแก้ไขได้

→ ลอง **"Reparse"** ก่อน รอผลใหม่แล้วตรวจสอบอีกครั้ง

### กรณีที่ 3 — รูปแบบเอกสารเปลี่ยน Parser ไม่รู้จัก

→ **"Reject"** และแจ้งทีมเทคนิคพร้อมแนบไฟล์แนบ (ดูบทที่ 7)

### กรณีที่ 4 — ไม่ใช่ Rate Sheet (เป็นอีเมลทั่วไป)

→ **"Reject"** และตรวจสอบการตั้งค่า Source Email Keywords

## 4.5 SOP-REVIEW-002: Batch Approve

ใช้เมื่อต้องการอนุมัติหลายรายการพร้อมกันสำหรับสายเรือเดียว

**เงื่อนไขการใช้งาน:** ตรวจสอบตัวอย่างแล้วมั่นใจว่าข้อมูลถูกต้อง

<div class="procedure" markdown="block">

1. ใน Parse Review → Pending Approval
2. ระบุสายเรือที่ต้องการอนุมัติทั้งหมด
3. คลิกปุ่ม **"Batch Approve"** สำหรับสายเรือนั้น
4. ยืนยันการดำเนินการ

</div>

!!! warning "คำเตือน"
    ใช้ Batch Approve เฉพาะเมื่อตรวจสอบคุณภาพข้อมูลเบื้องต้นแล้วเท่านั้น เนื่องจากไม่มีการถามยืนยันรายการ

---

## 4.6 SOP-REVIEW-003: Reparse

<div class="procedure" markdown="block">

1. ในแถวของรายการที่ต้องการ Reparse คลิกปุ่ม **"Reparse"** (สีม่วง)
2. ระบบลบผลเดิมและเริ่มวิเคราะห์ใหม่
3. รอประมาณ 1-3 นาที
4. รีเฟรชหน้า Parse Review เพื่อดูผลใหม่

</div>

---

## 4.7 การติดตามสถิติ Parse Review

ผู้บริหารควรติดตามตัวชี้วัดต่อไปนี้เป็นประจำ:

| ตัวชี้วัด | เป้าหมาย | วิธีตรวจสอบ |
|---------|---------|-----------|
| อัตราการวิเคราะห์สำเร็จ | ≥ 90% | Job Logs: (completed / total parse jobs) |
| ระยะเวลารอการอนุมัติ | ≤ 24 ชั่วโมง | ตรวจสอบ timestamp ใน Parse Review |
| รายการค้างอนุมัติ | ≤ 10 รายการ | Parse Review → Pending count |

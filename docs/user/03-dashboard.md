## 3.2 ส่วนประกอบของหน้า Dashboard

### 3.2.1 แถบนำทาง (Navigation)

แถบนำทางด้านซ้ายแสดงเมนูที่ผู้ใช้งาน Sale สามารถเข้าถึงได้:

| เมนู | ฟังก์ชัน |
|------|---------|
| Dashboard | หน้าภาพรวม (หน้าปัจจุบัน) |
| Rate Query | ค้นหาอัตราค่าระวาง |
| โปรไฟล์ | จัดการข้อมูลส่วนตัว |

### 3.2.2 การ์ดสถิติ (Statistics Cards)

หน้า Dashboard แสดงการ์ดสถิติสำคัญ ได้แก่:

| การ์ด | ความหมาย |
|-------|---------|
| อีเมลทั้งหมด | จำนวนอีเมล Rate Sheet ที่ระบบดึงมาสะสม |
| อัตราค่าระวาง | จำนวนแถวอัตราค่าระวางในระบบ |
| สายเรือ | จำนวนสายเรือที่มีข้อมูลในระบบ |
| ปรับปรุงล่าสุด | เวลาที่มีการเพิ่มข้อมูลล่าสุด |

### 3.2.3 สถานะระบบ

Dashboard แสดงสถานะการทำงานของระบบ ท่านสามารถตรวจสอบว่ามีข้อมูลใหม่รอดูหรือไม่

---

## 3.3 การนำทางไปยังหน้าอื่น

จาก Dashboard สามารถไปยังหน้าหลักได้โดย:

- คลิกเมนูด้านซ้าย
- คลิกปุ่มหรือลิงก์ใน Dashboard โดยตรง (หากมี)

!!! tip "เคล็ดลับ"
    หน้า **Rate Query** คือหน้าหลักที่ท่านจะใช้งานบ่อยที่สุด สามารถเข้าถึงได้ตลอดเวลาจากเมนูด้านซ้าย

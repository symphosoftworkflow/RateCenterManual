# บทที่ 4 — การค้นหาอัตราค่าระวาง

*DOC-USR-001 v1.0 | คู่มือผู้ใช้งาน*

## 4.1 ภาพรวม

หน้า **Rate Query** คือหน้าหลักสำหรับ **ค้นหาและดูอัตราค่าระวาง** ที่ระบบรวบรวมจากสายเรือต่าง ๆ ท่านสามารถกรองข้อมูลตามเกณฑ์ต่าง ๆ และดาวน์โหลดเอกสารต้นฉบับ

---

2. ระบบแสดงหน้าค้นหาพร้อมตัวกรอง

</div>

## 4.3 ตัวกรองการค้นหา

### 4.3.1 ตัวกรองหลัก (จำเป็น)

| ตัวกรอง | คำอธิบาย | ตัวอย่าง |
|---------|---------|---------|
| **ปี** (Year) | ปีของอัตราค่าระวาง | 2026 |
| **เดือน** (Month) | เดือนที่มีผล | มีนาคม |

!!! note "หมายเหตุ"
    ต้องเลือก ปี และ เดือน ก่อนเสมอ เพื่อจำกัดข้อมูลที่แสดง

### 4.3.2 ตัวกรองเพิ่มเติม

| ตัวกรอง | คำอธิบาย | ตัวอย่าง |
|---------|---------|---------|
| **POL** (ท่าเรือต้นทาง) | เลือกจาก dropdown | LAEM CHABANG |
| **POD** (ท่าเรือปลายทาง) | เลือกจาก dropdown | SINGAPORE |
| **สายเรือ** (Carrier) | เลือกได้หลายสายเรือ | COSCO, HMM |
| **ประเภทตู้** | เลือกประเภทที่ต้องการ | 20DC, 40HQ |

### 4.3.3 ตัวกรองขั้นสูง

| ตัวกรอง | คำอธิบาย |
|---------|---------|
| **Zone** | โซนพื้นที่ปลายทาง |
| **Country** | ประเทศปลายทาง |
| **Trade** | เส้นทางการค้า (Trade Lane) |
| **T/T** | Transit Time |

---

## 4.4 การค้นหาข้อมูล

<div class="procedure">

1. เลือก **ปีและเดือน** ที่ต้องการ
2. ระบุ **POL** และ/หรือ **POD** (ถ้ามี)
3. เลือก **สายเรือ** ที่ต้องการ (ถ้ามี)
4. เลือก **ประเภทตู้** ที่ต้องการ (ถ้ามี)
5. คลิกปุ่ม **"ค้นหา"** (Search)
6. ระบบแสดงผลลัพธ์ในตาราง

</div>

---

## 4.5 การอ่านผลลัพธ์

<div class="screenshot-placeholder">
[รูปที่ 4.2: ตารางผลลัพธ์การค้นหา]
</div>

**คำอธิบายคอลัมน์หลักในตาราง:**

| คอลัมน์ | คำอธิบาย |
|---------|---------|
| สายเรือ | ชื่อ/รหัสสายเรือ |
| POL | ท่าเรือต้นทาง |
| POD | ท่าเรือปลายทาง |
| อัตรา 20DC | ค่าระวางตู้ 20 ฟุต (USD) |
| อัตรา 40DC | ค่าระวางตู้ 40 ฟุต (USD) |
| อัตรา 40HQ | ค่าระวางตู้ 40HQ (USD) |
| Surcharge | ค่าธรรมเนียมเพิ่มเติม |
| T/T | ระยะเวลาขนส่ง (วัน) |
| F/T | ระยะเวลาปลอดค่าใช้จ่าย (วัน) |
| วันหมดอายุ | วันสุดท้ายที่อัตรานี้มีผล |

### 4.5.1 การกำหนดคอลัมน์ที่แสดง

ท่านสามารถ **เลือกคอลัมน์ที่ต้องการแสดง** ได้โดย:

<div class="procedure">

1. คลิกปุ่ม **"คอลัมน์"** (Columns) ด้านบนตาราง
2. เลือก/ยกเลิกคอลัมน์ที่ต้องการ
3. ตารางอัปเดตตามที่เลือก

</div>

## 4.6 การดาวน์โหลดเอกสารแนบ

ท่านสามารถดาวน์โหลดไฟล์ Rate Sheet ต้นฉบับที่สายเรือส่งมาได้

<div class="procedure">

1. ในแถวของอัตราค่าระวางที่ต้องการ คลิกปุ่ม **"ดูอีเมล"** (View Email)
2. ระบบแสดงหน้าต่างรายละเอียดอีเมลต้นทาง
3. คลิกชื่อไฟล์แนบเพื่อดาวน์โหลด

</div>

## 4.7 การเลือกรายการสำหรับส่งออก

สามารถเลือกเฉพาะรายการที่ต้องการแล้วส่งออกเป็น Excel ได้

<div class="procedure">

1. ทำเครื่องหมายถูกในช่อง Checkbox ของแถวที่ต้องการ
2. สามารถเลือกทั้งหมดได้โดยคลิก Checkbox ที่หัวตาราง
3. คลิกปุ่ม **"ส่งออกที่เลือก"** (Export Selected)
4. กรอกหมายเหตุ (Comment) ถ้ามี
5. คลิก **"ดาวน์โหลด"**

</div>

---

## 4.8 การแบ่งหน้า (Pagination)

หากผลลัพธ์มีจำนวนมาก ระบบจะแบ่งเป็นหลายหน้า

- คลิกหมายเลขหน้าหรือปุ่ม **"ถัดไป"** / **"ก่อนหน้า"** เพื่อเปลี่ยนหน้า
- เลือก **จำนวนรายการต่อหน้า** ได้จาก dropdown (ปกติ 10, 20, หรือ 50 รายการ)

---

## 4.9 คำแนะนำการค้นหา

| เป้าหมาย | วิธีค้นหาที่แนะนำ |
|---------|----------------|
| เปรียบเทียบอัตราหลายสายเรือ | เลือก POL + POD + เดือน แต่ไม่จำกัดสายเรือ |
| หาอัตราตู้เฉพาะ | เลือกประเภทตู้ที่ต้องการ |
| ดูอัตราทั้งหมดของสายเรือหนึ่ง | เลือกเฉพาะสายเรือนั้น + เดือน |
| ค้นหาตามปลายทาง | ระบุ POD + เดือน |

!!! tip "เคล็ดลับ"
    หากไม่แน่ใจรหัสท่าเรือ ให้กรอกตัวอักษรบางส่วนในช่อง POL/POD แล้วระบบจะแสดงรายการให้เลือก

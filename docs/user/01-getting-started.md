## 1.1 ภาพรวมระบบ

ระบบ **RateSheetExtractor** เป็นระบบสารสนเทศที่ช่วยให้ท่านสามารถ **ค้นหาและดาวน์โหลดข้อมูลอัตราค่าระวางสินค้าทางทะเล** จากสายเรือต่าง ๆ ได้อย่างรวดเร็วและสะดวก โดยไม่ต้องค้นหาในอีเมลหรือเอกสาร PDF ด้วยตนเอง

ระบบรวบรวมข้อมูลอัตราค่าระวางจาก **15 สายเรือ** ที่สำคัญ และจัดเก็บในรูปแบบที่สามารถค้นหาและกรองได้ตามต้องการ

## 1.2 ข้อกำหนดสำหรับผู้ใช้งาน

### 1.2.1 ความรู้พื้นฐานที่จำเป็น

| ด้าน | ระดับที่จำเป็น |
|------|--------------|
| การใช้งานเบราว์เซอร์ (Chrome, Edge, Firefox) | พื้นฐาน |
| การใช้งาน Microsoft Excel | พื้นฐาน (สำหรับการส่งออกข้อมูล) |
| ความรู้เกี่ยวกับรหัสท่าเรือ (POL/POD) | พื้นฐาน |

### 1.2.2 สิ่งที่ต้องมี

- บัญชีผู้ใช้งาน (Username และ Password) ที่ได้รับจากผู้ดูแลระบบ
- คอมพิวเตอร์ที่เชื่อมต่ออินเทอร์เน็ต
- เบราว์เซอร์ที่รองรับ (แนะนำ Google Chrome)

## 1.4 การเข้าถึงระบบ

ระบบทำงานผ่านเบราว์เซอร์ ไม่ต้องติดตั้งโปรแกรมเพิ่มเติม

<div class="procedure" markdown="block">

1. เปิดเบราว์เซอร์ (แนะนำ Google Chrome)
2. พิมพ์ URL ของระบบ (รับจากผู้ดูแลระบบ) ในช่อง Address Bar
3. กด **Enter** เพื่อเปิดหน้าเข้าสู่ระบบ

</div>

!!! tip "เคล็ดลับ"
    บันทึก URL ของระบบเป็น Bookmark ในเบราว์เซอร์เพื่อความสะดวกในการเข้าถึงครั้งต่อไป

## 2.1 การเข้าสู่ระบบ (Login)

<div class="procedure">

1. เปิดเบราว์เซอร์และไปที่ URL ของระบบ
2. ระบบแสดงหน้าจอเข้าสู่ระบบ
3. กรอก **Username** ในช่องแรก
4. กรอก **Password** ในช่องที่สอง
5. คลิกปุ่ม **"เข้าสู่ระบบ"** (Login)

</div>

## 2.2 การเปลี่ยนรหัสผ่านครั้งแรก (Force Password Change)

เมื่อเข้าสู่ระบบครั้งแรก ระบบจะบังคับให้ท่าน **ตั้งรหัสผ่านใหม่** ก่อนใช้งาน

<div class="procedure">

1. หลังเข้าสู่ระบบด้วยรหัสผ่านที่ได้รับ ระบบแสดงหน้า "เปลี่ยนรหัสผ่าน"
2. กรอก **รหัสผ่านใหม่** ที่ต้องการ
3. กรอก **ยืนยันรหัสผ่าน** อีกครั้ง
4. ตรวจสอบว่าตัวบ่งชี้ความปลอดภัยแสดง "แข็งแกร่ง" (Strong) หรือ "ดีมาก"
5. คลิก **"เปลี่ยนรหัสผ่าน"**

</div>

<div class="screenshot-placeholder">
[รูปที่ 2.2: หน้าจอเปลี่ยนรหัสผ่านครั้งแรก]
</div>

**ข้อกำหนดรหัสผ่าน:**

| เงื่อนไข | ข้อกำหนด |
|---------|---------|
| ความยาวขั้นต่ำ | **8 ตัวอักษร** |
| ตัวพิมพ์ใหญ่ (A-Z) | อย่างน้อย **1 ตัว** |
| ตัวพิมพ์เล็ก (a-z) | อย่างน้อย **1 ตัว** |
| ตัวเลข (0-9) | อย่างน้อย **1 ตัว** |
| อักขระพิเศษ | อย่างน้อย **1 ตัว** เช่น `!@#$%^&*` |

**ตัวอย่างรหัสผ่านที่ดี:** `MyPass@2568`

!!! tip "เคล็ดลับ"
    เลือกรหัสผ่านที่จำได้ง่ายสำหรับตัวท่าน แต่คนอื่นคาดเดาได้ยาก ไม่ควรใช้ชื่อ วันเกิด หรือข้อมูลส่วนตัวที่คนอื่นอาจทราบ

---

## 2.3 ปัญหาในการเข้าสู่ระบบ

| ปัญหา | แนวทางแก้ไข |
|-------|-----------|
| Username หรือ Password ไม่ถูกต้อง | ตรวจสอบ Caps Lock และกรอกใหม่ |
| ลืม Password | ติดต่อผู้ดูแลระบบเพื่อขอรีเซ็ตรหัสผ่าน |
| บัญชีถูกระงับ | ติดต่อผู้ดูแลระบบ |
| หน้าจอไม่แสดง | ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต |

---

## 2.4 การออกจากระบบ (Logout)

<div class="procedure">

1. คลิกชื่อผู้ใช้งานที่มุมขวาบนของหน้าจอ
2. คลิก **"ออกจากระบบ"** (Logout)
3. ระบบกลับสู่หน้าเข้าสู่ระบบ

</div>

!!! warning "ข้อควรระวัง"
    ควรออกจากระบบทุกครั้งหลังเสร็จสิ้นการใช้งาน โดยเฉพาะบนเครื่องคอมพิวเตอร์สาธารณะหรือที่ใช้ร่วมกัน

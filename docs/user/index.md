## 1. วัตถุประสงค์

เอกสารฉบับนี้จัดทำขึ้นเพื่อเป็นแนวทางการใช้งานสำหรับ **ผู้ใช้งานทั่วไป (Sale)** ในการค้นหา ดู และส่งออกข้อมูลอัตราค่าระวางจากระบบ RateSheetExtractor

---

## 2. ขอบเขต

คู่มือนี้ครอบคลุมหัวข้อต่อไปนี้:

- การเข้าสู่ระบบและการตั้งรหัสผ่าน
- การใช้งานหน้า Dashboard
- การค้นหาอัตราค่าระวางพร้อมตัวกรองต่าง ๆ
- การดาวน์โหลดเอกสารแนบ
- การส่งออกข้อมูลอัตราค่าระวางในรูปแบบ Excel
- การจัดการโปรไฟล์และรหัสผ่าน

**ขอบเขตที่ไม่ครอบคลุม:** การตั้งค่าระบบ การจัดการผู้ใช้งาน และการอนุมัติข้อมูล ซึ่งอยู่ในขอบเขตของผู้ดูแลระบบ (ดู DOC-ADM-001)

---

## 3. กลุ่มผู้ใช้เอกสาร

| บทบาท | คำอธิบาย |
|-------|-----------|
| **Sale** | พนักงานขายหรือผู้ที่ต้องการค้นหาและส่งออกอัตราค่าระวาง |

---

## 4. บทนิยามและคำย่อ

| คำ / คำย่อ | ความหมาย |
|-----------|----------|
| **Rate Sheet** | เอกสารอัตราค่าระวางสินค้าทางทะเล |
| **POL** | Port of Loading — ท่าเรือต้นทาง |
| **POD** | Port of Discharge — ท่าเรือปลายทาง |
| **T/T** | Transit Time — ระยะเวลาขนส่ง (วัน) |
| **F/T** | Free Time — ระยะเวลาปลอดค่าใช้จ่าย (วัน) |
| **Surcharge** | ค่าธรรมเนียมเพิ่มเติมนอกจากอัตราค่าระวางพื้นฐาน |
| **20DC** | ตู้คอนเทนเนอร์ขนาด 20 ฟุต ทั่วไป |
| **40DC** | ตู้คอนเทนเนอร์ขนาด 40 ฟุต ทั่วไป |
| **40HQ** | ตู้คอนเทนเนอร์ขนาด 40 ฟุต High Cube |
| **FWD** | Freight Forwarder — ตัวแทนขนส่ง |
| **Dashboard** | หน้าจอภาพรวมสถิติระบบ |

# บทที่ 6 — การจัดการโปรไฟล์

*DOC-USR-001 v1.0 | คู่มือผู้ใช้งาน*

---

## 6.1 ภาพรวม

ผู้ใช้งานทุกคนสามารถดูและแก้ไขข้อมูลโปรไฟล์ของตนเองได้ รวมถึงการเปลี่ยนรหัสผ่าน

---

## 6.2 การดูโปรไฟล์

<div class="procedure">

1. คลิกชื่อผู้ใช้งานหรือไอคอนโปรไฟล์ที่มุมขวาบนของหน้าจอ
2. คลิก **"โปรไฟล์"** (Profile)
3. ระบบแสดงข้อมูลส่วนตัวของท่าน

</div>

<div class="screenshot-placeholder">
[รูปที่ 6.1: หน้าจอโปรไฟล์ผู้ใช้งาน]
</div>

**ข้อมูลที่แสดง:**

| รายการ | คำอธิบาย |
|--------|---------|
| Username | ชื่อเข้าสู่ระบบ (ไม่สามารถแก้ไขได้) |
| ชื่อ-นามสกุล | ชื่อแสดงในระบบ |
| อีเมล | อีเมลติดต่อ |
| บทบาท | Sale / Admin / Superadmin |
| แผนก | แผนกที่สังกัด |
| บริษัท | บริษัทที่สังกัด |

---

## 6.3 การเปลี่ยนรหัสผ่าน

<div class="procedure">

1. ในหน้าโปรไฟล์ คลิกแท็บ **"เปลี่ยนรหัสผ่าน"** (Change Password)
2. กรอก **รหัสผ่านปัจจุบัน** (Current Password)
3. กรอก **รหัสผ่านใหม่** (New Password)
4. กรอก **ยืนยันรหัสผ่านใหม่** (Confirm Password)
5. ตรวจสอบตัวบ่งชี้ความปลอดภัยว่าแข็งแกร่งเพียงพอ
6. คลิก **"เปลี่ยนรหัสผ่าน"**

</div>

<div class="screenshot-placeholder">
[รูปที่ 6.2: หน้าจอเปลี่ยนรหัสผ่าน]
</div>

**ข้อกำหนดรหัสผ่าน:**

| เงื่อนไข | ข้อกำหนด |
|---------|---------|
| ความยาวขั้นต่ำ | 8 ตัวอักษร |
| ตัวพิมพ์ใหญ่ | อย่างน้อย 1 ตัว |
| ตัวพิมพ์เล็ก | อย่างน้อย 1 ตัว |
| ตัวเลข | อย่างน้อย 1 ตัว |
| อักขระพิเศษ | อย่างน้อย 1 ตัว |

!!! warning "ข้อควรระวัง"
    หากลืมรหัสผ่านปัจจุบัน ไม่สามารถเปลี่ยนรหัสผ่านเองได้ ต้องติดต่อผู้ดูแลระบบเพื่อรีเซ็ต

---

## 6.4 นโยบายการใช้งานบัญชี

| นโยบาย | รายละเอียด |
|--------|-----------|
| ห้ามแชร์บัญชี | บัญชีผู้ใช้งาน 1 บัญชีต่อ 1 คน |
| การออกจากระบบ | ออกจากระบบทุกครั้งเมื่อเสร็จสิ้นการใช้งาน |
| รหัสผ่าน | ห้ามบอกรหัสผ่านให้ผู้อื่น |
| เครื่องสาธารณะ | ไม่ควรบันทึกรหัสผ่านในเบราว์เซอร์บนเครื่องสาธารณะ |

---

## 6.5 คำถามที่พบบ่อย

**ถาม: เปลี่ยน Username ได้หรือไม่?**  
ตอบ: ไม่ได้ Username ถูกกำหนดเมื่อสร้างบัญชีและไม่สามารถเปลี่ยนแปลงได้ หากต้องการเปลี่ยน ต้องให้ผู้ดูแลระบบสร้างบัญชีใหม่

**ถาม: ลืมรหัสผ่านทำอย่างไร?**  
ตอบ: ติดต่อผู้ดูแลระบบ (Admin) ขอให้รีเซ็ตรหัสผ่าน จากนั้นเข้าสู่ระบบด้วยรหัสผ่านใหม่และเปลี่ยนรหัสผ่านทันที

**ถาม: ระบบ Logout อัตโนมัติหรือไม่?**  
ตอบ: ใช่ หาก Token หมดอายุ ระบบจะ Logout อัตโนมัติและต้องเข้าสู่ระบบใหม่

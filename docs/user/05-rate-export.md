## 5.1 ภาพรวม

ระบบรองรับการส่งออก (Export) ข้อมูลอัตราค่าระวางเป็นไฟล์ Excel (.xlsx) ในหลายรูปแบบ เพื่อรองรับการใช้งานที่แตกต่างกัน

---

## 5.2 รูปแบบการส่งออก

| รูปแบบ | ผู้ใช้งาน | รายละเอียด |
|--------|---------|-----------|
| **Sale Person Format** | พนักงานขาย | ข้อมูลครบถ้วนพร้อมคอลัมน์ Surcharge แบบแยกรายการ |
| **FWD Format** | ตัวแทนขนส่ง | รูปแบบพิเศษสำหรับนำเข้าในระบบของ Freight Forwarder |
| **Selected Rates** | ทุกคน | ส่งออกเฉพาะรายการที่เลือก พร้อมช่องใส่หมายเหตุ |

---

## 5.3 การส่งออกจากหน้า Rate Query

### 5.3.1 ส่งออกรายการที่เลือก (Export Selected)

<div class="procedure">

1. ค้นหาอัตราค่าระวางตามที่ต้องการ (ดูบทที่ 4)
2. เลือกรายการด้วย Checkbox ในตาราง
3. คลิกปุ่ม **"ส่งออกที่เลือก"** (Export Selected)
4. ระบบเปิดหน้าต่างยืนยัน
5. กรอก **หมายเหตุ** (Comment) หากมี เช่น ชื่อลูกค้า หรือหมายเลขใบเสนอราคา
6. คลิก **"ดาวน์โหลด"**
7. ไฟล์ Excel จะดาวน์โหลดอัตโนมัติ

</div>

## 5.4 การส่งออกจากหน้า Rate Export

หน้า **Rate Export** ให้ส่งออกข้อมูลอัตราค่าระวาง**รายเดือน**ทั้งหมด

!!! note "หมายเหตุ"
    หน้า Rate Export เข้าถึงได้จากเมนูหลัก สำหรับผู้ดูแลระบบ (Admin) ในการส่งออกข้อมูลจำนวนมาก

### 5.4.1 ส่งออก Sale Person Format

<div class="procedure">

1. คลิกเมนู **Rate Export** (สำหรับ Admin)
2. เลือก **เดือน** และ **ปี** ที่ต้องการ
3. คลิกปุ่ม **"ดาวน์โหลด Sale Format"**
4. ไฟล์ Excel ดาวน์โหลดอัตโนมัติ

</div>

**โครงสร้างไฟล์ Excel Sale Person Format:**

| คอลัมน์ | รายละเอียด |
|---------|-----------|
| สายเรือ | ชื่อสายเรือ |
| POL | ท่าเรือต้นทาง |
| POD | ท่าเรือปลายทาง |
| Zone / Trade | โซน / เส้นทางการค้า |
| อัตรา 20DC | ค่าระวาง (USD) |
| อัตรา 40DC | ค่าระวาง (USD) |
| อัตรา 40HQ | ค่าระวาง (USD) |
| [Surcharge columns] | ค่าธรรมเนียมแต่ละประเภท |
| รวม 20DC | รวมทุกค่าใช้จ่าย |
| รวม 40DC | รวมทุกค่าใช้จ่าย |
| รวม 40HQ | รวมทุกค่าใช้จ่าย |
| T/T | ระยะเวลาขนส่ง |
| F/T | ระยะเวลาปลอดค่าใช้จ่าย |
| Routing | เส้นทาง |
| วันหมดอายุ | วันที่อัตรานี้หมดอายุ |

### 5.4.2 ส่งออก FWD Format

<div class="procedure">

1. ในหน้า Rate Export เลือก เดือนและปี
2. คลิกปุ่ม **"ดาวน์โหลด FWD Format"**
3. ไฟล์ Excel ดาวน์โหลดอัตโนมัติ

</div>

รูปแบบ FWD ออกแบบมาเฉพาะสำหรับนำเข้าในระบบ FWD ของบริษัท โดยมีการจัดเรียงคอลัมน์และรูปแบบข้อมูลตามที่กำหนด

---

## 5.5 การเปิดไฟล์ Excel ที่ดาวน์โหลด

<div class="procedure">

1. ไฟล์จะอยู่ในโฟลเดอร์ **Downloads** ของคอมพิวเตอร์
2. ดับเบิลคลิกไฟล์เพื่อเปิดใน Microsoft Excel
3. หากระบบถาม Protected View คลิก **"Enable Editing"**

</div>

!!! tip "เคล็ดลับ"
    ตั้งชื่อไฟล์ก่อนบันทึก เพื่อให้ค้นหาได้ง่ายในภายหลัง เช่น `Rate_COSCO_June2026.xlsx`

---

## 5.6 ปัญหาการส่งออกที่พบบ่อย

| ปัญหา | แนวทางแก้ไข |
|-------|-----------|
| ไฟล์ไม่ดาวน์โหลด | ตรวจสอบว่าเบราว์เซอร์อนุญาตการดาวน์โหลด |
| ไฟล์เปิดแสดงตัวอักษรผิด | ตรวจสอบว่า Excel รองรับ Unicode (UTF-8) |
| ข้อมูลในไฟล์ว่างเปล่า | ไม่มีข้อมูลตรงกับเงื่อนไขที่เลือก — ลองเปลี่ยนเดือน/ปี |
| ไม่สามารถเลือกรายการได้ | ตรวจสอบว่ากรอกเงื่อนไขการค้นหาและคลิก "ค้นหา" แล้ว |
